# 附录 A 角色—菜单—页签矩阵

本附录是权限速查表：菜单级见第 2.4 节，本附录补齐页签与按钮级，并给出模块操作对照。权威来源为 `tenant-ui-permission.json`（1.23）与《角色菜单权限对照》V1.3。

## A.1 页签与按钮资源号

页签与按钮同为资源号，6 位数字。菜单可见而页签不可见属正常，此时页面上不渲染该页签。

| 资源号 | 所属菜单 | 名称 | 授予角色 |
| --- | --- | --- | --- |
| `520001` | 绩效/盘点 | 物料盘点 | `ADMIN`、`UltiMng` |
| `520002` | 绩效/盘点 | 管理驾驶舱 | `ADMIN`、`IPMT`、`PDGM`、`SYSGM`、`TM`、`TGM`、`QCGM`、`FGGM`、`UltiMng` |
| `520003` | 绩效/盘点 | 项目仪表盘 | `520002` 全部角色，另加 `PDM`、`PJM` |
| `520004` | 绩效/盘点 | 组织工作量 | 同 `520002` |
| `520801` | 测试管理 | 测试汇总 | `TM`、`TGM`、`UltiMng` |
| `521801` | 产品管理 | 预算汇总 | `PDGM`、`UltiMng` |

三处易误判：

1. `SM`（系统工程师）能看到“绩效/盘点”菜单吗？不能，`SM` 的 9 项菜单中不含 `5200`；`SYSGM` 才有。

3. `PDM` 能看到“管理驾驶舱”吗？不能，只能看项目仪表盘。菜单相同而页签不同，是常见疑问来源。

## A.3 立项与档案的按钮白名单

| 按钮 | 资源号 | 位置 | 仅授予 | 用途 |
| --- | --- | --- | --- | --- |
| 编辑分类 | `520101` | 立项管理 > 分类区 | `UltiMng` | 维护立项分类 |
| 废弃 | `520102` | 立项管理 > 项目行 | `UltiMng` | 废弃项目，未结束特性与工单按规则终止 |
| 创建直接立项 | `520103` | 立项管理 > 列表顶部 | `UltiMng` | 跳过预立项直接建项目 |
| 档案操作 | `520301` | 档案管理 > 文件行 | `UltiMng` | 档案的归档、移动等管理动作 |

机构管理员不具备上述四项。若机构管理员在页面上找不到“废弃”“直接立项”，属设计如此，不是配置错误。

## A.4 模块操作对照

模块操作决定“能不能写”，与菜单决定“能不能看”相互独立。常见模块与操作：

| 模块 | 主要操作 | 典型使用页面 |
| --- | --- | --- |
| `WORKER` | 查看、新增、修改 | 团队管理、假日设置、权限配置 |
| `MAIL` | 查看、新增、修改、删除 | 内部邮件 |
| `SUMMARY` | 查看 | 绩效/盘点四个页签 |
| `CBB` | 查看、新增、修改、审批 | 特性仓库、CBB 定义与审核 |
| `DEMAND` | 查看、新增、修改、删除 | 需求识别 |
| `PRE_PROJECT` | 查看、新增、修改、提交 | 预立项管理 |
| `PROJECT` | 查看、新增、修改、审批 | 立项管理、项目管理 |
| `JOB_ITEM` | 查看、新增、修改、审核、审批 | 研发管理、工期管理、系统工程、评审管理 |
| `MATERIAL` | 查看、新增、修改、删除、审批 | 物料管理 |
| `WAREHOUSE` | 查看、新增、修改 | 仓库管理 |
| `INVENTORY` | 查看、新增、修改、导出 | 库存管理 |
| `QUALITY` | 查看、新增、修改、审批 | 质量管理、质量反馈、测试管理 |
| `PRODUCT` | 查看、新增、修改 | 产品管理 |
| `BUDGET` | 查看、新增、修改、审批 | 预算管理 |
| `PERFORMANCE` | 查看 | 绩效管理 |
| `FILE` | 查看、新增、修改、删除 | 档案管理、文档下载 |
| `FLOW` | 查看、新增、修改 | 流程配置 |
| `MANHOUR` | 查看、新增、修改 | 执行管理（我的任务、工时） |

排障用法：页面能打开但保存失败时，用附录 B 查出该页面的模块，再对照本表与第 18.2 节确认本角色是否具备对应写操作。

## A.5 菜单数核对清单

上线验收或任命后核对时，逐角色数侧栏项数即可，不必逐项比对：

| 角色 | 应有菜单数 | 常见偏差原因 |
| --- | --- | --- |
| `STAFF` | 8 | 多了岗位菜单说明被任命；少了说明模板或覆盖异常 |
| `PDM`、`PDGM`、`PJM` | 14 | 三者数量相同但内容不同，须比内容 |
| `IPMT` | 13 | 少了预算管理说明未列入委员会 |
| `SM` | 9 | —— |
| `SYSGM`、`TM`、`TGM`、`QCGM` | 10 | `TM` 为 8 说明尚未被指定为子项目测试主管 |
| `FGGM` | 9 | —— |
| `MATM` | 11 | 为 8 说明物料部负责人未设置 |
| `ADMIN` | 12 | 为 25 说明同时是最终管理人 |
| `UltiMng` | 25 | 少于 25 说明最终管理人设置未生效或未重登 |
