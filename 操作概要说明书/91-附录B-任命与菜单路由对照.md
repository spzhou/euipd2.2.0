## B.3 机构与账号的关键约定

| 项 | 约定 |
| --- | --- |
| 平台机构标识 | `fm4ek0Zy`，名称“平台超级用户（Mock）”，其管理员即 `SUPER` |
| 机构标识 | 新建机构时由系统生成，登录页不展示 |
| 登录名 | 2 至 6 位，机构维度唯一 |
| 管理员判定 | 机构联系电话等于登录手机号，一号一管理员 |

| 初始口令 | 新建机构取机构联系电话，新建成员取成员标识，首次登录强制修改 |
| 数据隔离 | 业务表按机构标识行级隔离，跨机构不可见 |

## B.4 登录结果的四个清单

登录后前端持有四份清单，排查“为什么看不到/点不动”时按顺序看：

| 清单 | 内容 | 影响 |
| --- | --- | --- |
| 角色清单 | `roleList`，如 `STAFF`、`PDM` | 决定套用哪些菜单模板，多角色取并集 |
| 资源清单 | 可用资源号，含菜单、页签、按钮 | 决定菜单与页签是否渲染 |
| 模块操作 | 形如 `PROJECT:VIEW`、`PROJECT:CREATE` | 决定接口是否受理 |
| 受管资源 | 平台登记的受管资源号全集 | 未登记的资源号默认放行，已登记的须在可用清单内 |

因此同一现象可能由不同清单引起：菜单不显示查资源清单；按钮能点但保存失败查模块操作。两者都不是“重新登录一定能解决”的问题，须核对任命与机构覆盖。
