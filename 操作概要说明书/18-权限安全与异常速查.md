# 第 18 章 权限、安全与异常速查

## 18.1 权限的三层闸门

看不到、点不动、调不通，是三个不同层级的问题。判定前先分清在哪一层被拦：

| 层 | 控制对象 | 资源形式 | 被拦时的表现 |
| --- | --- | --- | --- |
| 第一层：菜单 | 侧栏是否出现该菜单 | 四位数菜单资源号，如 `5209` | 侧栏无该菜单；直接输地址会被带回欢迎页 |
| 第二层：页签与按钮 | 页面内的页签、行内按钮是否出现 | 六位资源号或“模块:操作” | 页面能进，但页签或按钮不显示 |
| 第三层：接口 | 后端是否允许该请求 | Scope 与机构数据范围 | 页面报错，通常带拒绝码 |

三层都通过才叫“有权限”。**菜单有而按钮没有是正常的**，例如 `QCGM` 能看到绩效/盘点但看不到物料盘点页签。

### 18.1.1 判定顺序

出现“我没有某个功能”时，按以下顺序自查：

1. 角色对不对：在 `团队管理 > 资质设置` 与 `组织关系` 中确认自己是否在对应名单或是否为部门负责人。
2. 是否重新登录：角色按任命即时计算，任命或改任后必须退出重登。
3. 菜单资源号是否在自己的角色模板内（查附录 A）。
4. 页签与按钮是否在自己的白名单内（查附录 A）。
5. 数据归属是否对：例如“项目经理”只在本项目生效，跨项目即无操作权。
6. 单据状态是否允许：按钮常因状态未到而不显示（如特性集成需全部工单完成）。

前五步是权限，第六步是状态。两者表现相同，处理方式完全不同。

## 18.2 登录与会话速查

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 提示账号或口令错误 | 口令错；或用了初始口令之外的口令 | 核对；连续失败会锁定 |
| 提示已锁定 | 15 分钟内失败 5 次 | 等 15 分钟；紧急时由管理员重置口令 |
| 登录后强制改口令 | 首次登录或口令被重置 | 设置新口令，不得与原口令相同 |
| 登录机构下拉没有我的机构 | 手机号只在一个机构；或机构未启用 | 核对手机号与机构状态 |
| 同一手机号有多个机构 | 允许多机构 | 登录时选择“登录机构” |
| 提示请求过于频繁 | 公开接口 30 次/分钟/来源地址 | 稍后重试，批量操作放慢 |
| 操作中突然回登录页 | 刷新令牌被拒或会话失效 | 重新登录；页面会带原地址回跳 |
| 长时间不操作后报错 | 访问令牌 30 分钟过期 | 系统会自动续期一次，失败则重登 |
| 换账号后看到上一个人的数据 | 同浏览器复用会话 | 每次切换账号先退出，或用无痕窗口 |

口令规则：8 至 32 位，必须同时含字母与数字。机构管理员初始口令为机构联系电话，成员初始口令为成员标识。

## 18.3 按钮不显示速查

| 场景 | 常见原因 | 处置 |
| --- | --- | --- |
| 立项管理没有“创建直接立项项目” | 不是最终管理人 | 由平台超管设置最终管理人 |
| 立项管理没有“编辑分类”“废弃” | 同上（按钮仅 `520103`、`520102`） | 同上 |
| 档案管理没有“档案操作” | 按钮 `520301` 仅属最终管理人 | 由最终管理人操作 |
| 项目管理没有“项目评审” | 仍有子项目未完成 | 收口子项目评审 |
| 项目管理没有“归档” | 项目未完成，或本人非产品经理/监管委员 | 先完成项目，再由有资格人归档 |
| 研发管理没有“特性集成” | 该特性仍有工单未完成 | 推进测试与缺陷闭环 |
| 特性处理没有“分解” | 状态不允许，或不是该子项目经理 | 核对状态与身份 |
| 物料管理没有“发料确认” | 单据不在待发料 | 等项目经理批准 |
| 执行管理没有“退料” | 领料未发料 | 等发料确认 |
| 测试管理看不到“单元测试管理” | 项目未立项 | 等立项批准 |
| 系统工程看不到“系统工程列表” | 该页签仅属 `SYSGM` | 由系统总监查看 |
| 预立项管理没有“发起立项” | 无已批准特性，或预立项非 `ACTIVE` | 先审批特性 |
| 停用/废弃 CBB 按钮不显示 | 不是 CBB 管理方 | 由最终管理人处理 |

## 18.4 拒绝码速查

| 拒绝码 | 含义 | 出现在 | 处置 |
| --- | --- | --- | --- |
| `NO_PERMISSION` | 无该操作权限 | 启动研发、跨子项目操作 | 核对是否该项目/子项目负责人 |
| `DEV_VERSION_DUPLICATE` | 同产品下主开发版本重复 | 新建预立项、迭代 | 换版本号 |
| `DEV_VERSION_LOCKED` | 版本已锁定 | 编辑预立项、改主开发版本 | 走迭代 |
| `ITERATION_DEV_VERSION_SAME` | 迭代目标版本与源版本相同 | 项目迭代 | 按升级方式取更高版本 |
| `CHARACTER_REVISION_IN_PROGRESS` | 同一特性已有修订在进行 | 发起修订 | 等当前修订完成 |
| `CHARACTER_UPDATE_STATUS_INVALID` | 特性状态不允许迭代 | 重复勾选已迭代特性 | 换特性或等迭代完成 |
| `MILESTONE_REFERENCED` | 里程碑已被特性引用 | 删除里程碑 | 先改特性里程碑 |
| `SETUP_MILESTONE_REQUIRED` | 立项至少需要一个里程碑 | 提交立项 | 补里程碑 |
| `REVIEW_ALREADY_IN_PROGRESS` | 同一对象已有进行中的评审 | 发起评审 | 等当前评审结束 |
| `REVIEW_COO_NOT_ALL_SUBMITTED` | 委员未全部提交 | 组长审结 | 催办委员 |
| `REVIEW_TASK_UNFINISHED` | 增补任务未完成 | 组长再次审结 | 先完成增补任务 |
| `JOB_ITEM_STATUS_INVALID` | 工单状态不允许该操作 | 重复提交里程碑评审发起单、处理已关闭工单 | 刷新列表，按当前状态重走 |
| `CBB_PUBLISH_GATE_FAILED` | 发布为 CBB 的内容校验未通过 | 评审选“作为特性发布” | 补全特性描述与接口定义 |
| `PROJECT_JOB_FORBIDDEN_WHEN_REVIEWING` | 评审期间禁止下发主项目任务 | 下发任务 | 评审结束后下发 |
| `PROJECT_ARCHIVE_ACTOR_INVALID` | 归档人无资格 | 项目/子项目归档 | 由产品经理或监管委员归档 |
| `MATERIAL_STOCK_SHORT` | 库存不足 | 物料申请 | 减少数量或补入库 |
| `REQUEST_TOO_FREQUENT` | 请求过于频繁 | 公开接口 | 放慢重试 |
| `TOKEN_EXPIRED`／`TOKEN_INVALID` | 令牌过期或无效 | 任意接口 | 重新登录 |

拒绝码不一定直接显示给用户，页面可能只给一句中文提示；排查时以提示文案 + 操作时间在日志中定位。

## 18.5 流程卡住速查

| 卡在哪 | 典型原因 | 处置 |
| --- | --- | --- |
| 需求一直 `SUBMIT` | 产品经理未下发 | 催办；核对需求归属预立项 |
| 特性一直 `SUBMIT` | 系统工程师未给意见，或同工单下还有特性未给 | 逐条补全意见 |
| 立项一直 `SETUP` | 监管委员未审批 | 催办；核对立项申请的监管委员 |
| 子项目建不了 | 主项目未 `SETUPED` | 先完成立项批准 |
| 特性一直 `SETUPED` | 未“启动研发” | 由子项目经理启动 |
| 研发工单一直 `SUBMIT` | 项目经理未审核或未评价 | 催办 |
| 测试工单提交被拒 | 存在未关闭子缺陷 | 闭环缺陷 |
| 特性一直 `INTEGRATION` | 集成工单未评价 | 由子项目经理评价 |
| 评审主单一直 `HANDLING` | 委员未提交 | 催办委员 |
| 评审已通过但主单未 `COMPLETED` | 评审通知未确认 | 到“评审通知”确认 |
| 子项目评审批不了 | 仍有特性未归档 | 完成剩余特性评审 |
| 项目评审发起不了 | 子项目未全部完成 | 收口子项目 |
| 质量单停在 `REJECT` | 质量总监未重新提交结案 | 催办并复核 |
| 领料单停在待发料 | 物料管理员未发料 | 催办发料 |
| 退料单停在待收料 | 物料管理员未收料 | 催办收料 |

## 18.6 角标异常

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 角标一直亮但列表为空 | 缓存未失效 | 刷新页面；角标缓存 45 秒 |
| 有新的待办但无角标 | 未到轮询周期或未刷新 | 角标 20 分钟轮询一次，重要事项用列表核对 |
| 邮件未读角标不准 | 邮件角标 60 秒轮询 | 稍等或刷新 |
| 处理完角标不减 | 数据未收口（如工单被驳回又回到你） | 核对是否为新的待办 |

角标只是提示，**业务判定以列表里的状态与下一节点为准**。

## 18.7 安全须知

### 18.7.1 账号与口令

1. 一人一号，不共用；初始口令首次登录必须修改。
2. 口令 8 至 32 位含字母与数字，不使用机构电话、成员标识等可猜值。
3. 连续失败会锁定，误锁等待 15 分钟或由管理员重置。
4. 管理员重置口令后，本人下次登录仍需改口令。

### 18.7.2 会话与令牌

| 项 | 取值 |
| --- | --- |
| 访问令牌有效期 | 30 分钟 |
| 刷新令牌 | 空闲 8 小时、最长 24 小时 |
| 过期处理 | 自动续期一次并重试原请求；失败清会话回登录页 |
| 多端登录 | 同一账号可在不同浏览器登录，切换账号请先退出 |

### 18.7.3 数据隔离

系统为多租户：业务数据按机构隔离，跨机构不可见。平台超管只能管理“机构/团队”，不能直接进入某机构的研发页面；直接输入研发页面地址会被带回欢迎页。

### 18.7.4 留痕

关键操作都有办理记录：处理人、时间、结论与意见。办理记录不可修改、不可删除；意见写错只能追加。审计时以办理记录与流程实例为准。

## 18.8 办理记录与审计取证

### 18.8.1 在哪看

| 对象 | 入口 |
| --- | --- |
| 工单 | 工单详情 > 办理记录 |
| 特性 | 特性详情 > 过程页签 |
| 项目 | 项目详情 > 过程与基线 |
| 单据流程实例 | `/customer/flow` > 进度页签（按业务主键） |
| 评审 | 评审详情 > 评审意见页签 |

### 18.8.2 取证清单

报告缺陷或申诉时，至少提供五项：

1. 登录账号与角色（角色码）。
2. 菜单与页面名称、资源号（如 `5209`）。
3. 操作时间（精确到分钟）与操作对象编号。
4. 页面提示原文或拒绝码。
5. 截图或流程实例截图。

五项齐全时，运维可直接在日志与流程实例中定位，不必反复复现。

## 18.9 常见问题

| 问题 | 答复 |
| --- | --- |
| 任命后多久生效 | 重新登录即生效，无需等缓存 |
| 为什么同一人在两个项目里权限不同 | 项目级角色按项目判定，不是全局 |
| 能不能临时给某人开一个菜单 | 最终管理人可在权限配置中调整，但侧栏入口已下线，需实施人员操作 |
| 管理员能不能给自己加菜单 | 不能，管理员列与最终管理人列为锁定列 |
| 会话过期会丢数据吗 | 表单未保存内容会丢；建议长表单分段保存 |
| 办理记录能不能删 | 不能，任何角色都不能 |
| 跨机构能不能看到同名项目 | 不能，按机构隔离 |
| 平台超管能不能改机构业务数据 | 不能，只能管理机构与管理员 |
| 出现“请求过于频繁”要不要报缺陷 | 不需要，属限流保护，放慢重试 |
| 提示文案与实际原因不符怎么办 | 记下时间与对象编号，按 18.8.2 取证后报缺陷 |
