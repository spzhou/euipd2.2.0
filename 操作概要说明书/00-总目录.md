# EUIPD 研发管理系统 角色操作说明书

| 项 | 内容 |
| --- | --- |
| 文档性质 | 面向最终用户的角色操作说明书（按角色分册 + 端到端主线） |
| 版本 | V1.0（首版，18 章正文 + 4 个附录 + 修订记录） |
| 编制日期 | 2026-10-25 |
| 适用系统 | EUIPD 研发管理系统（gateway / system / customer / file 四进程） |
| 权限基线 | `tenant-ui-permission.json` 1.23；《角色菜单权限对照》V1.3 |
| 流程基线 | `Architecture/程序流程/` 01 至 20（2026-10-11 修订版） |
| 验证基线 | 《全系统功能测试方案》V1.8（197 条）、全流程端到端测试（188 条）、《全系统功能测试报告》V2.4 |
| 读者对象 | 平台超级管理员、机构管理员、最终管理人、各岗位角色、实施与培训人员 |

本书解决两个问题：**我这个角色在哪个页面做什么**（角色分册，第 4 至 15 章），**一张单据按什么顺序在角色之间流转**（端到端主线，第 16 章）。两者用菜单资源号、业务状态码与用例编号交叉索引，同一操作只在角色分册详述一次，主线只写顺序与交接。

## 一、阅读路径

| 读者 | 建议路径 | 说明 |
| --- | --- | --- |
| 平台超级管理员 | 第 2 章 → 第 3 章 → 第 4 章 → 第 16.2 节 | 只做开户与设最终管理人，不进入机构业务 |
| 机构管理员 | 第 3 章 → 第 5 章 → 第 16.2 节 | 管人与日历，不代办业务 |
| 最终管理人 | 第 3 章 → 第 6 章 → 第 16 章 | 身份全权，含直接立项与仓库库存 |
| 岗位角色 | 第 3 章 → 对应角色章 → 第 16 章相关阶段 | 先掌握通用操作，再看本职菜单 |
| 新员工（无任命） | 第 3 章 → 第 15 章 | 8 项通用菜单即可完成需求、工单、档案、邮件 |
| 实施与培训 | 第 2 章 → 第 16 章 → 第 18 章 → 附录 | 先跑通主线，再补权限与异常 |
| 运维与支持 | 第 18 章 → 附录 A/B/C/D | 权限、状态码、菜单路由、拒绝码与资源号速查 |
