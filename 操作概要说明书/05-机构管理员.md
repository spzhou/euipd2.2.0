# 第 5 章 机构管理员（`ADMIN`）

## 5.1 角色定位与边界

机构管理员是“管人”的角色：建成员、任命岗位、维护部门与资质、设置日历、看绩效。它不代办业务，不参与立项审批、评审、仓库与库存。

| 项 | 说明 |
| --- | --- |
| 角色码 | `ADMIN`，由“登录手机号 = 机构联系电话”确定 |
| 菜单 | 12 项：8 项通用 + 团队管理、假日设置、绩效/盘点、绩效管理 |
| 页签 | 绩效/盘点的四个页签中只有“物料盘点” |
| 不读机构覆盖 | 机构覆盖调整不影响本角色菜单 |
| 不在范围内 | 立项审批、评审、质量分析、仓库、库存、直接立项、档案操作、预算调整 |
| 与最终管理人的区别 | 管理员 12 项；最终管理人 25 项。二者可由同一人担任 |

一句话判断：凡涉及“人的状态与任命”的由管理员做；凡涉及“单据流转与资金物料”的由最终管理人或岗位角色做。

## 5.2 首次登录

### 5.2.1 适用角色与目的

新任机构管理员。目的：以初始口令进入并设置私人口令。

### 5.2.2 操作步骤

1. 用管理员手机号登录，选择本机构。
2. 口令填初始口令（即机构联系电话）。
3. 填写验证码，点击【登录】。
4. 弹出“设置新密码”对话框，填写新密码与确认密码。
5. 确认后进入工作台。

### 5.2.3 字段说明

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 新密码 | 是 | 8 至 32 位，含字母与数字 |
| 确认密码 | 是 | 与新密码一致 |

初始口令本身不满足新口令规则（通常为纯数字手机号），不能作为新口令重复使用。

### 5.2.4 结果与留痕

改口令后进入工作台，侧栏 12 项；若该管理员同时是最终管理人，则为 25 项。

### 5.2.5 异常与处置

提示“不得使用初始口令”时换一个新口令；提示口令格式不符时按 8 至 32 位、字母加数字重填。

## 5.3 团队管理总览

### 5.3.1 入口

`研发管理 > 团队管理`（资源号 `5212`，路由 `/customer/worker`）。

### 5.3.2 页面构成

团队管理是页签式页面，五个页签各管一类事：

| 页签 | 用途 | 本章小节 |
| --- | --- | --- |
| 员工列表 | 成员的新增、编辑、删除、口令重置、移交、导入 | 5.4 |
| 职级管理 | 职级代码、名称与工时费率 | 5.5 |
| 资质设置 | 委员会、产品经理、项目经理、系统工程师四份名单 | 5.7 |
| 组织关系 | 部门结构与成员归属，部门负责人即总监与物料管理员 | 5.8 |
| 标准费率 | 团队标准工时费率 | 5.6 |

原“权限管理”页签已停用，权限调整不走此处。

## 5.4 员工列表

### 5.4.1 适用角色与目的

机构管理员、最终管理人。目的：维护本机构在职人员，为后续任命与派工提供对象。

### 5.4.2 入口

`团队管理 > 员工列表`。

### 5.4.3 页面构成

| 区域 | 内容 |
| --- | --- |
| 顶部 | 【下载员工信息表模板】、按部门筛选、关键词搜索、每页条数 |
| 列表 | 序号、工号、手机、姓名、职级、职务、岗位名称、创建时间、所在部门、状态 |
| 行操作 | 【编辑】【移交】【重置密码】【删除】 |

行操作的可用性由状态决定：管理员本人无【移交】与【删除】；最终管理人无【删除】；【重置密码】只对可重置的成员显示。

### 5.4.4 新增成员

#### 操作步骤

1. 在员工列表点击【添加员工】。
2. 填写手机号码、姓名、专业、学历、职务、职级、加入时间、状态等字段。
3. 点击【保存】。
4. 保存后在提示中确认成员已建立（系统不显示初始口令）。

#### 字段说明

| 字段 | 必填 | 规则 | 说明 |
| --- | --- | --- | --- |
| 员工ID | —— | 只读，新建时为空 | 保存后由系统生成 |
| 手机号码 | 是 | 11 位手机号 | 即登录名；同一手机号全局唯一 |
| 姓名 | 是 | —— | 列表按此显示 |
| 专业 | 是 | —— | 成员资料 |
| 学历 | 是 | —— | 成员资料 |
| 学位 | 否 | —— | 成员资料 |
| 生日 | 否 | 日期 | 成员资料 |
| 能力描述 | 否 | 文本 | 成员资料 |
| 员工头像 | 否 | 图片 | 不传则用默认头像 |
| 工作地址 | 否 | 文本 | 成员资料 |
| 工号 | 否 | 文本 | 列表“工号”列 |
| 职务 | 是 | 文本 | 列表“职务”列 |
| 标准岗位名称 | 否 | 文本 | 列表“岗位名称”列 |
| 办公邮件 | 否 | 邮箱 | 成员资料 |
| 办公电话 | 否 | 文本 | 成员资料 |
| 职级 | 是 | 从职级管理中选择 | 决定工时费率 |
| 加入时间 | 是 | 日期 | 影响在职判断 |
| 状态 | 是 | 在职 / 离职等 | 离职后不能接单 |

#### 结果与留痕

成员建立后为“在职”，初始口令为成员标识，首次登录须改口令。新建对话框不含部门字段，部门归属在 5.8 处理。

#### 异常与处置

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 手机号被占用 | 该号已在本机构或其他机构存在 | 同一人跨机构任职应沿用同一手机号，不要重复建号 |
| 无法保存 | 用户数量达到机构上限 | 请平台超管调高上限 |
| 成员登录看不到菜单 | 未任命岗位角色 | 按 5.7 任命后让其重登 |

### 5.4.5 编辑成员

点击行内【编辑】，可修改姓名、手机号、职务、岗位名称、职级、状态、加入时间等。改手机号会改变登录名，须同步告知本人；改为离职会使其无法继续接单，但历史单据保留。

### 5.4.6 删除成员

点击行内【删除】。仅非管理员、非最终管理人的成员可删除；已产生业务数据的成员建议改为离职而非删除，以保留办理记录中的人员信息。

### 5.4.7 重置成员口令

点击行内【重置密码】，按提示确认。重置后该成员口令恢复为初始口令，下次登录须改口令；同时清除其登录失败计数与锁定。此操作是该成员忘记口令时的标准处置。

### 5.4.8 批量导入成员

#### 操作步骤

1. 点击【下载员工信息表模板】，得到 `import_workers_template.xlsx`。
2. 按模板填写，不要修改文件名与表头。
3. 上传填写后的文件。
4. 按提示核对成功与失败行，失败行按提示修正后重传。

#### 字段与校验

模板列与新增成员一致，必填列同 5.4.4。整批校验，存在错误行时该批不入库并提示错误行号，修正后整批重传，避免半批成功造成重复。

#### 结果与留痕

导入成功即建立成员，均为在职，初始口令为成员标识。导入不自动归入部门，须在组织关系中处理。

### 5.4.9 工作移交（行内【移交】）

用于成员离职或转岗时把在办事项转给他人，详见 5.9。

## 5.5 职级管理

### 5.5.1 适用角色与目的

机构管理员、最终管理人。目的：定义职级及其工时费率，供成员选择与绩效计算使用。

### 5.5.2 入口

`团队管理 > 职级管理`。

### 5.5.3 操作步骤

1. 查看现有职级列表（职级代码、职级名称、工时费率）。
2. 点击【添加职级】，填写职级代码、名称、工时费率，保存。
3. 需要修改时点击行内【编辑】。

### 5.5.4 字段说明

| 字段 | 必填 | 规则 | 示例 |
| --- | --- | --- | --- |
| 职级代码 | 是 | 唯一，按机构习惯命名 | `P5` |
| 职级名称 | 是 | 显示名 | 高级工程师 |
| 工时费率 | 是 | 数值，用于绩效工时费计算 | `80` |

### 5.5.5 结果与留痕

职级建立后可被成员选用。修改费率影响此后产生的绩效计算，历史数据不回溯。

### 5.5.6 异常与处置

职级代码重复时不保存；已被成员引用的职级不建议删除，改为调整费率或新增职级。

## 5.6 标准费率

### 5.6.1 适用角色与目的

机构管理员、最终管理人。目的：设置全机构统一的标准工时费率，作为绩效与预算的基准。

### 5.6.2 入口

`团队管理 > 标准费率`。

### 5.6.3 操作步骤与字段

1. 查看当前标准费率（新建机构默认为 60）。
2. 填写新的费率。
3. 保存。

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 团队标准工时费率 | 是 | 数值；系统只维护一个标准费率 |

### 5.6.4 结果与留痕

标准费率参与工时费折算。修改只影响之后的计算，不重算已完成的绩效周期。

## 5.7 资质设置（四份名单）

### 5.7.1 适用角色与目的

机构管理员、最终管理人。目的：通过名单任命 `IPMT`、`PDM`、`PJM`、`SM` 四类岗位角色。这是机构内最常用也最容易出错的操作。

### 5.7.2 入口

`团队管理 > 资质设置`。

### 5.7.3 页面构成

四个区块，每块左右两栏，左侧“可选人员”、右侧已任命成员：

| 区块 | 对应角色 | 用途 |
| --- | --- | --- |
| 编辑 IPMT/ITMT 成员 | `IPMT` | 监管委员，参与立项审批与评审 |
| 编辑 产品经理 成员 | `PDM` | 预立项、立项申请、特性审批、产品发布 |
| 编辑 项目经理 成员 | `PJM` | 项目管理、研发管理、物料申请 |
| 编辑 系统工程师 成员 | `SM` | 特性审核意见、分解复核、BOM |

### 5.7.4 操作步骤

1. 进入资质设置，定位到要调整的区块。
2. 在左侧“可选人员”中选中成员，移入右侧；或在右侧选中成员移出。
3. 点击该区块的保存按钮。
4. 告知当事人退出重新登录。

### 5.7.5 字段说明

| 项 | 说明 |
| --- | --- |
| 可选人员 | 本机构在职成员，可按姓名检索 |
| 已任命成员 | 当前名单；最终管理人以“最终管理人（默认）”显示且不可移出 |
| 名单性质 | 多选，一人可同时出现在四份名单 |

### 5.7.6 结果与留痕

保存后名单立即更新，页面不弹成功提示，以右侧名单显示为准。当事人重登后取得对应角色，菜单数增加。

### 5.7.7 异常与处置

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 保存后当事人菜单不变 | 未重登 | 退出重登 |
| 无法移出某人 | 其为最终管理人 | 先由平台超管改设最终管理人 |
| 名单为空但当事人说已任命 | 在其他机构任命 | 角色按机构计算，需在本机构任命 |
| 任命后仍不能审批 | 角色只是入口，还须是单据的当前节点责任人 | 核对单据下一节点 |

### 5.7.8 任命与菜单的对应关系

任命只是取得入口，不等于能代办他人工作。例如新任 `PDM` 能看到“立项管理”，但只能处理本人为下一节点的单据或被指派的评审。判断“为什么看不到某个按钮”时，先看角色，再看单据状态与责任人。

## 5.8 组织关系与部门负责人

### 5.8.1 适用角色与目的

机构管理员、最终管理人。目的：维护部门结构、把成员归入部门，并通过“部门负责人”产生五个总监角色与物料管理员。

### 5.8.2 入口

`团队管理 > 组织关系`。

### 5.8.3 页面构成

| 区域 | 内容 |
| --- | --- |
| 部门树 | 机构部门结构；开户时自动生成七个固定部门 |
| 未分配成员 | 尚未归入部门的成员，列表含工号、姓名、职级、职务、岗位名称 |
| 操作 | 选中成员后点【归入部门】，选择目标部门 |

### 5.8.4 把成员归入部门

1. 在部门树中查看目标部门。
2. 在“未分配”列表中勾选成员。
3. 点击【归入部门】，在弹窗中选择部门。
4. 确认后成员从“未分配”移入该部门。

### 5.8.5 部门负责人与角色的对应

编辑部门负责人会同步产生对应角色，这是总监与物料管理员唯一的任命入口。

| 部门 | 负责人对应角色 | 菜单数 | 影响 |
| --- | --- | --- | --- |
| 产品中心 | `PDGM` | 14 | 产品总监视角，含预算汇总页签 |
| 系统工程部 | `SYSGM` | 10 | 含系统工程页签 |
| 质量部 | `QCGM` | 10 | 质量管理 |
| 法规部 | `FGGM` | 9 | 合规参与，菜单最少 |
| 测试部 | `TGM` | 10 | 测试管理与测试汇总 |
| 物料部 | `MATM` | 11 | 物料、仓库、库存三菜单 |
| 研发中心等 | 不产生角色 | —— | 仅组织归属 |

机构尚无某总监记录时，编辑对应部门负责人会自动新建记录；已有记录则改由新负责人担任。

### 5.8.6 结果与留痕

部门归属影响统计口径与部门筛选，也影响绩效管理的部门视图。负责人变更影响对应角色的取得，当事人须重登。

### 5.8.7 异常与处置

物料管理员看不到仓库与库存，说明物料部负责人未设置为该成员；质量总监看不到质量管理，说明质量部负责人未设置。测试主管 `TM` 不在此设置，只能在子项目中指定。

## 5.9 工作移交

### 5.9.1 适用角色与目的

机构管理员、最终管理人。目的：成员离职或长期离岗时，把其名下在办事项一次性转给他人，避免单据停滞。

### 5.9.2 入口

`团队管理 > 员工列表 > 成员行【移交】`（管理员本人无此按钮）。

### 5.9.3 前置条件

- 移交人存在未完成事项（工单、待办等）。
- 接收人为本机构在职成员。

### 5.9.4 操作步骤

1. 点击【移交】，弹窗标题为“将某某的工作移交给…”。
2. 在“选择工作接收人”中选择接收人。
3. 查看预览区：按事项类别列出数量；无事项时提示“没有需要移交的事项”。
4. 确认后提交。
5. 在“历次移交记录”中核对本次记录（时间、移交人、接收人、操作人、事项合计）。

### 5.9.5 字段说明

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 工作接收人 | 是 | 本机构在职成员，单选 |

### 5.9.6 结果与留痕

移交后相关事项的责任人改为接收人，接收人登录后角标与我的任务出现这些事项。移交不改变单据状态，也不产生审批。

### 5.9.7 异常与处置

提示没有可移交事项时，说明该成员名下已无在办单据，无需移交。移交后接收人称看不到，先让其重登，再核对是否只移交了部分类别。

## 5.10 假日设置

### 5.10.1 适用角色与目的

机构管理员、最终管理人。目的：维护工作日历，使工期、负荷与绩效按实际工作日计算。

### 5.10.2 入口

`研发管理 > 假日设置`（资源号 `5228`）。

### 5.10.3 操作步骤

1. 选择日期范围（开始日期至结束日期）。
2. 选择类型：放假 / 上班 / 恢复默认。
3. 填写备注（如“国庆节”“国庆调休”，不超过 30 字）。
4. 点击【应用】。
5. 在月历与列表中核对结果；单日需要撤销时点该行的【恢复默认】。

### 5.10.4 字段说明

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 日期范围 | 是 | 起止两天，闭区间 |
| 类型 | 是 | 放假：不计工作日；上班：周末计为工作日；恢复默认：清除设置 |
| 备注 | 否 | 不超过 30 字 |

### 5.10.5 结果与留痕

设置后日历中对应日期变色，列表出现记录。影响面：

1. 工单计划完成时间与负荷曲线按工作日分摊，节假日不再分摊工时。
2. 绩效计算的工作日口径随之变化。
3. 已提交的计划不重算，仅影响之后的分摊与新建计划。

### 5.10.6 异常与处置

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 应用按钮不可点 | 未选满起止日期或正在保存 | 补全日期后再试 |
| 设置后负荷没变 | 负荷已按旧日历生成，或缓存未刷新 | 刷新页面；新建计划验证 |
| 误设整月放假 | 范围选错 | 选中该范围后选“恢复默认”重设 |

## 5.11 绩效/盘点（物料盘点页签）

### 5.11.1 适用角色与目的

机构管理员、最终管理人。目的：核对物料实物与账面，形成盘点结论。

### 5.11.2 入口

`研发管理 > 绩效/盘点 > 物料盘点`（按钮资源号 `520001`）。

### 5.11.3 与其他页签的差别

同一菜单下四个页签，管理员只可见“物料盘点”，其余三个（管理驾驶舱、项目仪表盘、组织工作量）不显示。这是按钮白名单的结果，不是加载失败。

### 5.11.4 结果与留痕

盘点数据取自库存模块，管理员在此只做核对与导出，不改库存数量；需要调整库存时由物料管理员在库存管理中做盘点调整（见 13.5）。

## 5.12 绩效管理

### 5.12.1 适用角色与目的

机构管理员、最终管理人。目的：按周期查看成员绩效明细，作为考核与沟通依据。

### 5.12.2 入口

`研发管理 > 绩效管理`（资源号 `5216`）。

### 5.12.3 页面构成

| 区域 | 内容 |
| --- | --- |
| 筛选 | 部门、绩效周期 |
| 列表 | 工号、姓名、部门、绩效周期、交付总工时(标准)、延期率、延期绩效折扣、绩效工时费、负荷率、绩效评分 |
| 行操作 | 查看明细 |

### 5.12.4 结果与留痕

页面只读，绩效由工时、交付与延期率按规则计算，不在此手工改分。发现数据异常时核对工时申报与工单评价是否完整。

### 5.12.5 异常与处置

某成员绩效为空：当月无有效工时申报或工单未评价。负荷率异常：核对假日设置与工单计划区间。

## 5.13 能力边界

| 不能做 | 原因 | 应由谁做 |
| --- | --- | --- |
| 审批立项、审结评审 | 不是决策角色 | `IPMT`、最终管理人 |
| 建项目、直接立项、废弃项目 | 立项按钮只授最终管理人 | `UltiMng` |
| 看仓库管理、库存管理 | 只授 `MATM` 与 `UltiMng` | 物料管理员 |
| 改机构菜单覆盖 | 只授最终管理人 | `UltiMng` |
| 指定测试主管 `TM` | 只能在子项目上指定 | 项目经理、最终管理人 |
| 维护流程定义 | 入口只授最终管理人 | `UltiMng` |
| 维护成员角色模板 | 权限配置入口已隐藏 | 按 6.7 由最终管理人经接口处理 |

## 5.14 常见问题

| 问题 | 处置 |
| --- | --- |
| 新建成员后对方登录还是 8 项菜单 | 未任命；按 5.7 任命后重登 |
| 任命了总监但对方没反应 | 检查是“部门负责人”还是“资质名单”，两者产生不同角色 |
| 测试主管任命不了 | `TM` 只能在立项或子项目中指定，见 9.2 |
| 成员离职后单据卡住 | 先做工作移交，再改状态为离职 |
| 部门树里没有某部门 | 先新建部门，再归入成员 |
| 物料盘点页签不显示 | 只有 `ADMIN`、`UltiMng` 可见；其它角色属正常 |
| 改了标准费率，历史绩效变了没有 | 不变。费率只影响之后的计算 |
| 假日设置影响哪些数据 | 工期分摊、负荷曲线、绩效工作日口径 |
| 能否把管理员身份转给别人 | 不能自助转移，须由平台超管【变更机构管理员】 |
