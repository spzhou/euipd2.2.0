## C.4 口令与解锁

| 项 | 说明 |
| --- | --- |
| 初始口令（机构） | 机构联系电话 |
| 初始口令（成员） | 成员标识 |
| 演示口令 | `zsp123456`（Customer 机构）／`zsp123`（平台与船舶机构） |
| 新口令规则 | 8 至 32 位，必须含字母与数字 |
| 锁定规则 | 15 分钟内失败 5 次，锁定 15 分钟 |
| 解锁方式 | 等待 15 分钟；或管理员在团队管理中重置口令 |
| 限流 | 公开接口 30 次/分钟/来源地址 |

开发环境需要强制解锁时，删除 Redis 中的 `euipd:auth:login-fail:{登录名}` 与 `euipd:auth:login-lock:{登录名}` 两个键即可，属运维操作，不在页面提供。

## C.6 编号与命名约定

| 对象 | 约定 | 示例 |
| --- | --- | --- |
| 登录名称 | 2 至 6 位 | `Custom` |
| 主开发版本 | `^(0[1-9]\|[1-9]\d)\.\d{2}\.\d{4}$` | `01.00.0001` |
| 特性编号 | 主开发版本 + `-` + 四位 | `01.00.0001-0002` |
| 物料编码 | 机构前缀 + `-M` + 三位 | `CUS-M001` |
| 项目代码 | 机构前缀 + 两位序号 | `CUS01` |
| 内容版本 | `Vx.y` | `V1.2` |
| 流程定义版本 | 第 n 版 | `V3` |

演示环境名称统一加机构前缀（如 `CUS-`），正文使用固定句式并写满字数下限，便于在办理记录与列表中检索。
