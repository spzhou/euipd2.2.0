# 第 3 章 开始使用（通用操作，全角色）

本章是所有角色共同的操作底座。角色分册只写差异，凡本章已说明的登录、列表、表单、流程动作、附件、邮件，不再重复。

## 3.1 访问与准备

| 项 | 要求 |
| --- | --- |
| 浏览器 | Chrome、Edge 最新版；不建议使用 IE 兼容模式 |
| 地址 | 由管理员提供的前端地址（开发环境为 `http://127.0.0.1:8080`），网关地址仅供排查使用 |
| 屏幕 | 建议 1440 像素以上宽度；部分单据表列较多，窄屏需横向滚动 |
| 准备 | 手机号、口令、验证码；首次登录准备新口令；被任命者确认任命已保存 |

同时使用多个账号时，每次切换前退出登录，或使用不同浏览器配置。同一浏览器多标签共用同一会话，复制标签页不会产生第二个登录态。

## 3.2 登录

### 3.2.1 适用角色与目的

全部角色。登录成功后进入工作台，并取得本人的菜单、页签、按钮与模块操作范围。

### 3.2.2 入口

登录页（未登录时访问任意地址都会跳转到此）。

### 3.2.3 操作步骤

1. 打开前端地址，进入登录页。
2. 填写**手机号码**。系统据此判断账号是否存在，并在该号码属于多个机构时列出可选机构。
3. 填写**密码**。
4. 填写**验证码**（图形码，看不清可点击刷新）。
5. 若出现**登录机构**下拉框，选择要进入的机构；仅属于一个机构时不显示该项。
6. 点击【登录】。

### 3.2.4 字段说明

| 字段 | 必填 | 规则 | 示例 |
| --- | --- | --- | --- |
| 手机号码 | 是 | 11 位手机号，须与机构内成员记录一致 | `13800001002` |
| 密码 | 是 | 见 3.6 口令规则；首次登录为初始口令 | — |
| 验证码 | 是 | 图形码，通常 4 位，区分大小写以页面为准 | — |
| 登录机构 | 多机构时必填 | 单选，决定进入哪家机构的数据范围 | 船舶智能化公司 |

### 3.2.5 结果与留痕

登录成功进入 `/welcome` 工作台；若此前访问过被拦截的地址，登录后回到该地址。侧栏按角色渲染，顶栏显示姓名，页脚显示前后端版本。

系统在登录时需要完成三件事，异常时按此定位：

1. 校验账号与口令。口令不以明文传输，前端先取该手机号的盐值，再提交加盐摘要；对比在服务端完成。
2. 计算角色。按任命得出 `roleList`，多角色取并集。
3. 下发权限。按角色模板生成可用菜单（资源号）、按钮白名单与模块操作范围，一并写入登录结果。

### 3.2.6 异常与处置

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 提示手机号或密码不正确 | 口令错、手机号不在该机构 | 核对口令；确认该手机号在此机构有成员记录 |
| 验证码错误 | 图形码过期或大小写不符 | 刷新图形码后重填 |
| 提示账号被锁定 | 15 分钟内连续失败达到 5 次 | 等待锁定到期，或由管理员重置口令解除 |
| 机构下拉为空 | 该手机号在多家机构均有记录但未取到列表 | 刷新页面；仍为空时联系管理员核对成员记录 |
| 登录后侧栏只有少数菜单 | 未被任命岗位角色 | 按 2.4 核对应有菜单；任命后须退出重登 |
| 提示访问过于频繁 | 同一来源地址请求过多 | 稍后重试；持续出现时联系运维 |

## 3.3 平台超级管理员的登录差异

平台超级管理员使用平台机构登录，登录页操作与其他角色相同，区别在登录之后：

1. 侧栏只显示“超级用户”组的“机构/团队”，不展开“研发管理”组。
2. 直接访问机构业务地址（如团队管理）会被弹回工作台，接口返回无权限。
3. 平台超管不能写机构的菜单覆盖，也不能代替机构管理员做业务操作。

若平台超管登录后仍看到机构菜单，说明选错了机构：退出后重新选择平台机构登录。

## 3.4 首次登录与口令

### 3.4.1 首次登录

新建机构时以机构联系电话作为管理员初始口令，新建成员时以成员标识作为初始口令。以初始口令登录不会直接进入系统，而是弹出“设置新密码”对话框，要求先改口令。

### 3.4.2 操作步骤

1. 用初始口令登录。
2. 在“设置新密码”对话框填写新密码与确认密码。
3. 点击确定，改口令成功后进入工作台。

### 3.4.3 字段说明

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 新密码 | 是 | 8 至 32 位，至少含字母与数字 |
| 确认密码 | 是 | 与新密码一致 |

### 3.4.4 结果与留痕

改口令成功后，本人全部会话被吊销，需用新口令重新登录；此前因口令错误产生的失败计数与锁定同时清除。管理员重置成员口令后，该成员下次登录同样进入改口令流程。

### 3.4.5 异常与处置

新口令不足 8 位或纯数字、纯字母时不通过；两次输入不一致时不通过。忘记口令时联系机构管理员在“团队管理”重置，或使用登录页的短信重置（须该手机号可接收短信）。

## 3.5 口令规则与账号锁定

| 项 | 规则 |
| --- | --- |
| 口令长度 | 8 至 32 位 |
| 口令组成 | 至少含字母与数字 |
| 失败计数 | 同一登录名 15 分钟内失败 5 次即锁定 |
| 锁定时长 | 15 分钟 |
| 解除方式 | 到期自动解除；登录成功、本人改口令、短信重置、管理员重置口令均会清除计数 |
| 公开接口限流 | 登录、刷新、验证码、取盐等公开接口按来源地址每分钟 30 次；超出时提示访问过于频繁 |

因口令锁定导致测试或演示中断时，应由管理员重置口令，不要反复尝试。

## 3.6 会话与令牌

| 项 | 规则 |
| --- | --- |
| 访问令牌 | 有效期 30 分钟 |
| 刷新令牌 | 空闲 8 小时失效，自登录起最长 24 小时 |
| 过期处理 | 接口返回未授权时，前端自动刷新一次并重试原请求，使用者通常无感知 |
| 刷新失败 | 清除本地会话，回到登录页，登录后回到原地址 |
| 主动退出 | 点击顶栏退出登录，当前会话令牌被吊销 |
| 多机构 | 一个账号属于多家机构时，切换机构会重新签发令牌，数据范围随机构变化 |

会话保存在浏览器本地存储中。清除浏览器数据、换浏览器或使用无痕窗口都会导致重新登录。

## 3.7 工作台

登录后的默认页面，用于每天开工时确认“有没有我的事”。

| 区块 | 内容 | 用途 |
| --- | --- | --- |
| 待办区块 | 与侧栏一致的各类待办与角标 | 点角标进入对应列表 |
| 我的工单 | 本人为执行人或下一节点的工单 | 直接进入处理 |
| 当月绩效 | 当月工时与绩效统计 | 核对申报是否齐全 |
| 负荷曲线 | 按工作日历分摊的未来负荷 | 接单前判断是否超负荷 |
| 近 6 个月交付 | 交付趋势 | 复盘与绩效沟通 |

工作台只读取数，不在此处修改单据。所有处理动作都在对应菜单页完成。

## 3.8 侧栏、页签与角标

### 3.8.1 侧栏

三组菜单：超级用户（仅平台超管）、我的邮件、研发管理。菜单不显示即为无权限，不要用地址栏尝试。

### 3.8.2 页签

部分菜单内分页签，页签另受按钮白名单约束，可能出现“菜单可见、页签不可见”。例如“绩效/盘点”的四个页签、测试管理的“测试汇总”、产品管理的“预算汇总”、系统工程的“系统工程”页签。

### 3.8.3 角标口径

角标分三类：红点（有事项）、未读数字（仅邮件）、列表标记（有数据可看）。同一菜单可能有多个触发源，任一成立即亮。

| 菜单 | 类型 | 触发条件 |
| --- | --- | --- |
| 我的邮件 | 未读数字 | 未读邮件数；60 秒独立轮询 |
| 预算管理 | 红点 | 存在待本人审的预算调整，且预算单处于已创建状态 |
| 立项管理 | 红点 | 本人为监管委员的项目处于待审批；或本人创建的立项草稿 |
| 项目管理 | 红点 | 项目通知、项目物料申请、项目费用申请中任一有待办 |
| 研发管理 | 红点 | 本人为下一节点的开发类工单；或子项目类、挂特性的待审工单；或相关物料、费用申请 |
| 测试管理 | 红点 | 测试相关待办 |
| 评审管理 | 红点 | 本人为下一节点的特性评审、纳入变更评审、子项目评审、里程碑评审中任一 |
| 产品管理 | 红点 | 产品通知待处理 |
| 质量管理 | 红点 | 质量提交、质量复核、质量定义提交、质量物料或费用申请中任一 |
| 质量反馈 | 红点 | 待复核的质量反馈 |
| 档案管理 | 红点 | 待审批的档案申请 |
| 物料管理 | 红点 | 领料或退料申请待处理（含项目侧与研发侧两类） |
| 预立项管理 | 红点 | 待审的定义类工单、本人创建的评估工单、待修订特性中任一 |
| 系统工程 | 红点 | 下一节点为本人的工单、待审的预立项定义类工单、存量功能类工单 |
| 执行管理 | 红点 | 与“我的任务”同口径的待办 |
| 工期管理 | 列表标记 | 与页面四个页签同口径，有数据即可展开 |
| 需求识别、特性仓库 | 列表标记 | 有列表数据 |

角标刷新机制：登录后加载，之后按周期轮询；结果有短时缓存，写操作会主动失效相关缓存。因此刚处理完的单子，角标可能延迟数十秒才消失，属正常现象。

## 3.9 顶栏与个人信息

| 位置 | 功能 | 说明 |
| --- | --- | --- |
| 左侧标题 | 返回工作台 | 点击标题回到 `/welcome` |
| 改密码图标 | 修改本人口令 | 需输入原口令与新口令；成功后会话吊销，需重新登录 |
| 退出图标 | 退出登录 | 吊销当前会话并回登录页 |
| 头像与姓名 | 个人信息 | 查看本人资料；可改的内容以弹窗中可编辑项为准 |

页脚的版本号（前端/后端）在报障时必须提供，便于定位部署版本。

## 3.10 列表页通用操作

绝大多数菜单是“上查询、中列表、下分页”的结构，操作方式一致：

1. **查询**：填写条件后点击【查询】；清空条件点【重置】。
2. **分页**：底部分页条切换页码与每页条数；切换后保持当前查询条件。
3. **进入详情**：点击行或行内【查看】/单据名称。
4. **行内操作**：编辑、提交、删除等按钮按状态与权限显隐；不显示即当前状态不允许或本角色无该操作。
5. **导出**：仅在授予导出操作时出现；导出的列与当前查询条件一致。
6. **批量操作**：勾选多行后使用顶部批量按钮；批量按钮同样受权限与状态约束。

列表默认按业务规则排序（通常为更新时间倒序），不提供任意列排序的页面以实际为准。若列表为空，先确认查询条件与机构是否正确，再确认是否被状态筛选挡住。

## 3.11 表单通用规则

| 规则 | 说明 |
| --- | --- |
| 必填 | 标星号；未填时提交被拦，定位到第一个未通过的字段 |
| 字数下限 | 正文类字段通常要求写满一定字数（如特性各节、评审工作描述不少于 10 字），过短不通过 |
| 字数上限 | 意见类通常 500 字以内，申请理由通常 2000 字以内，超长不通过 |
| 唯一性 | 项目代码、产品发布版本、预立方的产品与主开发版本组合等有唯一性校验 |
| 金额与工时 | 金额按科目精度录入；工时以小时为单位，按工作日历折算 |
| 附件 | 按页面提示的格式与大小上传；大文件走单独上传通道，上限 50 MB |
| 富文本 | 见 3.13，六节内容分别保存，可导入导出 Word |
| 保存与提交 | 【保存】只落库不改状态；【提交】进入流程并产生下一节点责任人 |

表单在填写过程中可随时保存草稿（状态为草稿或已保存），提交后修改受状态限制：已进入审批或已归档的单据不可再编辑，只能走撤回、驳回、修订或废弃。

## 3.12 流程类通用动作

| 动作 | 含义 | 出现位置 | 结果 |
| --- | --- | --- | --- |
| 保存 | 落库不流转 | 单据表单底部 | 状态不变或变为草稿 |
| 提交 | 送下一节点 | 单据表单底部 | 状态转为待审，责任人变更，角标点亮 |
| 撤回 | 取回已提交未处理的单 | 本人提交的单据详情 | 回到可编辑状态；已进入下一步的不可撤回 |
| 驳回 | 退回上一节点 | 审批、评审、审核页 | 回到处理中，须填写意见 |
| 通过 / 批准 | 同意并流转 | 审批、评审页 | 进入下一状态 |
| 审结 | 汇总意见给出结论 | 评审主单 | 主单完成，特性或子项按结论流转 |
| 办理记录 | 查看每次流转的人、时间、动作、意见 | 单据详情 | 只读 |
| 流程图 | 查看当前节点与已走路径 | 单据详情 | 只读；流程定义维护见 6.8 |

通用约束：需要意见的动作必须填写意见；同一动作重复点击只生效一次；提交后若下一节点无人（未指定委员、未指定测试主管等），流程会停在原地并提示，需补齐人员后再提交。

## 3.13 附件、富文本与在线文档

| 能力 | 入口 | 说明 |
| --- | --- | --- |
| 普通附件 | 表单内“附件”区 | 上传后随单据保存；可下载、删除（受权限与状态限制） |
| 富文本六节 | 特性、质量分析等页面的富文本区 | 六节分别为特性描述、接口定义、性能指标、安全要求、可靠性要求、兼容性要求 |
| 插入图片 | 富文本工具栏 | 上传至对象存储后插入，图片随文档版本保存 |
| 导入 Word | 富文本工具栏 | 将 Word 内容导入指定章节，导入后仍需人工校对格式 |
| 导出 Word | 单据详情的导出入口 | 生成正式文件，导出内容取自已保存的版本 |
| 在线查看 / 编辑 | 附件或文档的“在线查看” | 基于在线文档服务；服务未启动时只能下载后本地查看 |
| 版本对比与演进 | 特性详情的版本区 | 查看版本差异与演进关系，只读 |

富文本的每次保存形成版本，历史版本可查不可改。评审、归档以当时保存的版本为准，因此提交评审前应确认最新版本已保存。

## 3.14 内部邮件

内部邮件是全角色可用的站内沟通工具，与单据流程相互独立。

| 操作 | 入口 | 说明 |
| --- | --- | --- |
| 查看收件 | 我的邮件 > 邮箱 > 收件箱 | 未读邮件在侧栏显示未读数字，60 秒刷新 |
| 写邮件 | 我的邮件 > 写邮件 | 填写收件人、主题、正文，可加附件 |
| 回复 / 转发 | 邮件详情 | 回复保留原主题线索；转发可改收件人 |
| 草稿 | 邮箱 > 草稿箱 | 未发送的邮件可继续编辑或删除 |
| 已发送 | 邮箱 > 发件箱 | 只读，可再次转发 |
| 删除 | 邮件详情或列表 | 移入已删除，按页面提供的入口恢复或彻底删除 |

邮件不替代流程意见：需要留痕的审批意见、驳回原因必须写在单据里，邮件只作提醒。

## 3.15 遇到无权限时怎么处理

按现象分三种，处理路径不同：

1. **侧栏没有该菜单**：先按第 2.4 节确认本角色是否应有。应有而没有，说明任命未生效，退出重登；仍没有，请管理员核对任命或机构覆盖。
2. **地址能打开但被弹回工作台**：与第 1 种同因，按第 1 种处理。
3. **页面能进、按钮能点、保存报无权限**：菜单已授予但模块操作不足。按附录 B 查该页面所属模块，再对照第 18.2 节确认本角色是否本就不具备该写操作；若应有，请最终管理人核对机构覆盖。

不要通过重复点击或改用其他账号绕过：越权请求会被网关与服务侧两次拦截，且不产生业务数据。

## 3.16 常见问题

| 问题 | 处置 |
| --- | --- |
| 登录后菜单比同事少 | 岗位角色不同。按 2.4 核对；任命后须退出重登 |
| 任命了还是不生效 | 未重新登录；或任命保存在其他机构；或该角色有额外前置（`TM` 需先有子项目并指定测试主管） |
| 列表里看不到刚建的单据 | 查询条件含状态或时间；或单据在他人名下（按数据权限过滤） |
| 提交按钮不见了 | 单据状态已流转，或本角色不是当前节点责任人 |
| 提交后下一节点没人 | 未指定委员、测试主管或审核人，补齐人员后重新提交 |
| 角标不消失 | 缓存期内延迟，数十秒后自动刷新；超过 5 分钟仍在，核对单据是否真的处理完成 |
| 附件上传失败 | 超过大小上限或格式不符；大文件改用上传通道；仍失败时记录时间与文件名报障 |
| Word 导出内容为空 | 富文本未保存或版本未生成；先保存再导出 |
| 页面显示旧数据 | 浏览器缓存或列表未刷新；刷新页面；仍异常时提供页脚版本号报障 |
| 换机构后看不到原数据 | 数据按机构隔离，切换机构即切换数据范围 |
| 忘记口令 | 管理员在团队管理重置，或登录页短信重置 |
| 提示访问过于频繁 | 公开接口限流，稍后重试 |
