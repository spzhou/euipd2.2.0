# 第 13 章 物料管理员（`MATM`）

## 13.1 定位与菜单

物料管理员是研发物料仓库的“出纳与保管”：唯一能建仓库、入库、发料、收料的人。没有发料确认，研发领料不会扣库存；没有收料确认，退料不会回库存。

| 项 | 说明 |
| --- | --- |
| 角色码 | `MATM`，来自机构“物料部”负责人 |
| 菜单 | 11 项：8 项通用 + 物料管理（`5210`）、仓库管理（`5223`）、库存管理（`5225`） |
| 独占菜单 | 仓库管理、库存管理（最终管理人也可看到） |
| 无绩效/盘点 | `MATM` 不显示绩效/盘点菜单，物料盘点页签也只属管理员与最终管理人 |
| 主要交接对象 | 项目经理（领退料审批）、执行人（申请人）、机构管理员（物料部负责人调整） |

一个关键前提：**物料管理员是部门负责人产生的**。机构管理员在 `团队管理 > 组织关系 > 编辑部门` 中把物料部负责人改为某人，该人重新登录后即有 `MATM`。

## 13.2 仓库管理

### 13.2.1 适用角色与目的

物料管理员（以及最终管理人）。目的：建立与维护存放物料的仓库，供入库、领料、退料选择。

### 13.2.2 入口

`研发管理 > 仓库管理`（资源号 `5223`）。

### 13.2.3 页面内容

| 列 | 说明 |
| --- | --- |
| 仓库编码 | 机构内唯一，开户时自动生成 `LOCAL` |
| 仓库名称 | 默认“研发物料仓” |
| 存放地点 | 文本 |
| 说明 | 文本 |
| 状态 | 启用 / 停用 |
| 操作 | 编辑、停用（或启用） |

开户后系统自动建立默认仓库：编码 `LOCAL`，名称“研发物料仓”，状态启用。新建机构应先用它入库，不必另建。

### 13.2.4 新建仓库

1. 在仓库管理页点击【新增仓库】。
2. 填写仓库编码、仓库名称、存放地点、说明。
3. 保存。

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 仓库编码 | 是 | 机构内唯一，建议大写字母 |
| 仓库名称 | 是 | 可辨识 |
| 存放地点 | 否 | 文本 |
| 说明 | 否 | 文本 |

### 13.2.5 停用仓库

仓库停用后不再出现在入库、领料、退料的下拉列表中，已有库存与历史流水不受影响。有库存的仓库建议先清空再停用，否则库存只能查看无法出库。

### 13.2.6 异常与处置

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 编码重复不保存 | 已有同编码仓库 | 换编码 |
| 下拉里没有仓库 | 仓库已停用，或不是本机构 | 核对状态 |
| 想删除仓库 | 仓库只支持停用 | 用停用代替删除，保留流水可追溯 |

## 13.3 入库录入

### 13.3.1 适用角色与目的

物料管理员。目的：把实物入库数量与未税单价录入系统，形成库存与入库流水。入库单价决定移动加权平均单价，进而决定领料记账金额。

### 13.3.2 入口

`研发管理 > 库存管理 > 【入库录入】`。

### 13.3.3 前置条件

- 已有启用状态的仓库。
- 已确定物料编码、名称、单位与未税单价。

### 13.3.4 操作步骤

1. 进入库存管理，点击【入库录入】。
2. 选择仓库。
3. 填写物料编码、物料名称、规格型号、单位、数量、未税单价。
4. 按需填写批次号、外部单据号、供应商、说明。
5. 提交。
6. 在“库存”页签核对数量与单价，在“流水”页签核对入库记录。

### 13.3.5 字段说明

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 仓库 | 是 | 启用状态的仓库 |
| 物料编码 | 是 | 同仓库内唯一标识一种物料，建议 `机构前缀-M001` |
| 物料名称 | 是 | 文本 |
| 规格型号 | 否 | 文本 |
| 单位 | 是 | 与后续领用保持一致；改动会与既有库存冲突 |
| 数量 | 是 | 正数 |
| 未税单价 | 是 | 正数，保留四位小数参与加权平均 |
| 批次号 | 否 | 文本，用于批次追溯 |
| 外部单据号 | 否 | 采购或送货单号 |
| 供应商 | 否 | 文本，进入 BOM 时仍需在 BOM 行填写 |
| 说明 | 否 | 文本 |

### 13.3.6 结果与留痕

库存页签新增或累加该物料；未税单价按移动加权平均重算；流水页签记一条“入库”，含变动前、变动后与操作人。

同一物料第二次入库的单价计算：`新单价 =（原数量 × 原单价 + 本次数量 × 本次单价）÷（原数量 + 本次数量）`。例如 10 块 × 500 元与 10 块 × 600 元入库后，单价为 550.0000。

### 13.3.7 异常与处置

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 单位与既有库存不一致 | 同编码物料的单位不同 | 用原单位；确需改单位时新建物料编码 |
| 单价填成含税价 | 混淆含税与未税 | 填未税单价，税额在外部系统处理 |
| 数量填负数 | 入库只接受正数 | 冲减请走退料或处置，不做出库负数 |
| 入库后领料单价与录入价不同 | 属正常，取的是加权平均单价 | 核对加权计算结果 |

## 13.4 Excel 批量导入

### 13.4.1 适用角色与目的

物料管理员。目的：一次性导入多行物料入库，用于到货批次较多或历史数据初始化。

### 13.4.2 入口

`库存管理 > 【下载模板】`，填好后 `【Excel 导入】`。

### 13.4.3 操作步骤

1. 下载模板，按表头填写：仓库编码、物料编码、物料名称、规格型号、单位、数量、未税单价，可选批次号、外部单据号、供应商、说明。
2. 逐行核对单位与既有库存是否一致。
3. 上传文件并导入。
4. 如提示错误行号，修正后重新导入。
5. 在“流水”页签核对同批记录是否带同一导入批号。

### 13.4.4 导入规则

| 规则 | 说明 |
| --- | --- |
| 整批原子性 | 任一行校验失败，整批不入库，并提示错误行号与原因 |
| 必须导入后 | 不允许部分成功，避免库存与单据不一致 |
| 单位一致性 | 同一物料编码的单位必须与既有库存一致 |
| 批号 | 同一批导入的流水记同一导入批号，便于回退核对 |
| 数量与单价 | 均为正数；单价为未税价 |

### 13.4.5 异常与处置

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 整批未入库，提示第 3 行单位错误 | 单位与既有库存冲突 | 改为原单位后重新导入 |
| 提示仓库编码不存在 | 模板里的仓库编码写错或仓库已停用 | 用启用仓库的正确编码 |
| 导入成功但数量不对 | 模板中同一物料写多行 | 合并为一行，或用多次入库 |
| 重复导入 | 同一文件导了两次 | 冲减请走处置或退料流程，不删流水 |

## 13.5 库存与流水

### 13.5.1 适用角色与目的

物料管理员（以及被授权的项目经理、最终管理人）。目的：查询某物料的当前库存、单价与全部变动轨迹。

### 13.5.2 入口

`库存管理 > 库存页签` / `流水页签`。

### 13.5.3 页面内容

| 页签 | 列 |
| --- | --- |
| 库存 | 序号、仓库、物料编码、物料名称、规格型号、单位、库存数量、未税单价、库存金额、更新时间、操作 |
| 流水 | 时间、类型、仓库、物料编码、变动数量、变动前、变动后、单价、单据号、来源、操作人 |

筛选条件：库存按仓库与关键字；流水按仓库、物料编码、类型、日期区间。

### 13.5.4 流水类型的含义

| 类型 | 触发 | 方向 |
| --- | --- | --- |
| 入库 | 入库录入或 Excel 导入 | 增加 |
| 出库 | 发料确认 | 减少 |
| 退料入库 | 收料确认 | 增加 |
| 盘点调整 | 物料盘点提交 | 增加或减少 |

每条流水都有单据号，可用它反查领料单、退料单或盘点单。

### 13.5.5 操作要点

1. 库存金额 = 库存数量 × 未税单价，四舍五入到分。
2. 单价只在入库时变化，出库不改变单价（移动加权平均法）。
3. 流水不可修改、不可删除，发现录入错误用反向单据冲减。

## 13.6 发料确认

### 13.6.1 适用角色与目的

物料管理员。目的：领料单经项目经理批准后，由仓库实际发料并扣减库存。未发料前库存不变，申请人也不能处置或退料。

### 13.6.2 入口

`研发管理 > 物料管理`（资源号 `5210`）。

### 13.6.3 页面内容

| 列 | 说明 |
| --- | --- |
| 申请单号 / 申请标题 | 领料单或退料单标识 |
| 记账金额 | 按库存单价计算的金额 |
| 任务名称 / 子项目名称 | 物料使用去向 |
| 使用方式 | 资产化或费用化，影响是否需要处置 |
| 审批状态 | 待审批、已批准等 |
| 发料 / 收料 | “待发料”或“待收料”标签 |
| 退料状态 | 该领料单的退料情况 |
| 申请人 / 申请时间 | 提单人 |
| 操作 | 发料确认、收料确认 |

### 13.6.4 操作步骤

1. 打开物料管理，筛选“待发料”的领料单。
2. 核对物料、数量、申请人与去向。
3. 点击【发料确认】。
4. 按实际发料填写发料数量与说明（如出库备注）。
5. 提交。

### 13.6.5 字段说明

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 发料数量 | 是 | 不大于申请数量且不大于库存 |
| 发料说明 | 否 | 文本，建议写清批次或外观情况 |

### 13.6.6 结果与留痕

库存数量扣减、库存金额相应减少；流水记一条“出库”；领料单状态变为“批准（已发料）”；申请人可继续做物料处置或发起退料。发料数量小于申请数量时，差额视为未领，库存不扣。

### 13.6.7 异常与处置

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 列表里没有待发料单 | 项目经理未批准 | 等审批通过 |
| 发料数量不能大于库存 | 库存不足 | 先入库，或与项目经理确认减少数量 |
| 发错料想撤回 | 已扣库存 | 由申请人发起退料，经审批与收料确认回库 |
| 单价与申请时不同 | 申请后发生过入库，单价重算 | 以发料时点单价为准 |

## 13.7 收料确认

### 13.7.1 适用角色与目的

物料管理员。目的：退料单经项目经理批准后，由仓库实际收料并回增库存。未收料前库存不变，退料人不能提交复核。

### 13.7.2 入口

`研发管理 > 物料管理 > 待收料行【收料确认】`。

### 13.7.3 前置条件

- 退料单已由项目经理批准，状态为“待收料”。
- 原领料单为“已发料”状态。

### 13.7.4 操作步骤

1. 在物料管理筛选“待收料”。
2. 打开退料单，核对物料、数量与退回仓库。
3. 点击【收料确认】。
4. 填写收料说明（如外观、可再用性）。
5. 提交。

### 13.7.5 字段说明

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 收料数量 | 是 | 不大于退料申请数量 |
| 收料说明 | 否 | 文本，建议写明外观与可再用状态 |

### 13.7.6 结果与留痕

库存回增；流水记一条“退料入库”；原领料单数量按退料量扣减；退料人可提交处置复核。库存单价沿用当前加权平均单价，不按退料单上的历史单价回写。

### 13.7.7 异常与处置

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 退料单不在待收料 | 项目经理未批准 | 等审批 |
| 收料数量小于退料数量 | 实物短缺或损坏 | 按实际收料填写，并在说明中写明差异 |
| 收料后库存单价变化 | 加权平均重算 | 属正常 |
| 退料人在收料后仍不能提交 | 处置未完成 | 由退料人完成物料处置 |

## 13.8 领退料全流程中的位置

物料管理员处在流程的“两头”：

| 节点 | 谁办 | 库存是否变化 |
| --- | --- | --- |
| 提出物料申请 | 执行人 | 否 |
| 领料审批 | 项目经理（单价只读） | 否 |
| **发料确认** | **物料管理员** | 是，减少 |
| 退料申请 | 执行人 | 否 |
| 退料审批 | 项目经理 | 否 |
| **收料确认** | **物料管理员** | 是，增加 |
| 物料处置 | 执行人提交，项目经理复核 | 否（费用化处理，不改库存） |

质量工单的领料与研发领料走同一套流程，只是处置复核人为产品经理（见 11.9）。

## 13.9 物料编码与计量单位

| 约定 | 说明 |
| --- | --- |
| 编码结构 | 建议 `机构前缀-M` 加三位序号，如 `CUS-M001` |
| 一个编码一种物料 | 名称、规格、单位三者绑定，改任一项应新建编码 |
| 单位不可混用 | 米与个不能共用同一编码，否则加权平均价失去意义 |
| 同编码多供应商 | 允许，用入库时的供应商字段区分，单价按加权平均合并 |
| 停用物料 | 库存为 0 且不再采购时不删除，保留历史流水 |

## 13.10 边界与交接

| 不做的事 | 由谁做 |
| --- | --- |
| 审批领料与退料 | 项目经理（9.11） |
| 复核物料处置 | 项目经理或产品经理（质量场景） |
| 编辑 BOM 清单 | 集成阶段执行人、项目经理 |
| 项目预算的物料科目 | 产品经理在立项申请中填写 |
| 物料盘点提交 | 管理员与最终管理人（页签 `520001`） |
| 采购下单 | 本系统无采购菜单，在外部系统办理 |

交接清单：

1. 开户后先确认默认仓库“研发物料仓（`LOCAL`）”可用，再通知执行人领料。
2. 入库后核对单价，因为它是后续所有领料记账金额的基准。
3. 每天清一次“待发料”与“待收料”，避免执行人卡在处置环节。
4. 发现库存与实物不符，走盘点调整（由管理员或最终管理人提交），不做手工改数。

## 13.11 常见问题

| 问题 | 答复 |
| --- | --- |
| 为什么我没有绩效/盘点菜单 | `MATM` 菜单 11 项不含绩效/盘点，物料盘点页签也只属管理员与最终管理人 |
| 能不能删除仓库 | 只能停用，保留历史流水 |
| 能不能改入库单价 | 不能，只能通过再次入库影响加权平均价 |
| 为什么领料单批准了库存没减 | 还没做发料确认 |
| 为什么退料批准了库存没加 | 还没做收料确认 |
| 领料单能不能部分发料 | 可以，按实际发料数量填写，差额不扣库存 |
| 发料后发现发错料 | 让申请人发起退料，走审批与收料确认回库 |
| 采购在哪里办 | 本系统不提供采购管理，采购在外部系统办理，到货后在这里入库 |
